# نص التعليق الصوتي — للتسجيل بصوت امرأة حقيقي

يُسجَّل كل سطر كملف منفصل (1.wav … 6.wav) أو ملف واحد يبدأ كل سطر فيه عند التوقيت المكتوب.
النبرة: واثقة، دافئة، وسرعة متوسطة إلى سريعة.

| # | يبدأ عند | المدة القصوى | النص |
|---|---|---|---|
| 1 | 0.2 ث | 2.9 ث | فاست كراند، شركة عراقية لصناعة التطبيقات. |
| 2 | 3.2 ث | 2.7 ث | جودة لا تُقارَن، بسعر مناسب، وتنفيذ سريع. |
| 3 | 6.1 ث | 2.9 ث | تطبيق كامل، أندرويد وآيفون، بتسعة وتسعين دولاراً. |
| 4 | 9.1 ث | 2.4 ث | موقع إدارة ومبيعات، بخمسة وخمسين. |
| 5 | 11.6 ث | 2.2 ث | وموقع تعريفي، بخمسة وثلاثين. |
| 6 | 13.9 ث | 1.5 ث | تواصل معنا الآن! |

بعد التسجيل: ضع الملفات في مجلد ثم شغّل
`python3 audio.py <المجلد> out.wav` ثم أمر ffmpeg من README لتركيبه على الفيديو.
