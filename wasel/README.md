# منصة واصل — PHP + JSON + تسجيل دخول (بريد / كوكل / واتساب)

## التنصيب (3 خطوات)

### 1) ارفع الملفات
1. من DirectAdmin ← **File Manager** ← ادخل `public_html` وامسح ملفات الموقع القديم.
2. ارفع `wasel-full.zip` داخل `public_html` واضغط **Extract**.
3. لازم تشوف مباشرة داخل `public_html`: `index.php`، `install.php`، مجلد `wasel-engine`... (مو مجلد واحد فيه كل شي).

### 2) افتح صفحة التنصيب
افتح `https://دومينك/install.php`:
- تفحص السيرفر وتكلك إذا أكو مشكلة وشلون تحلها.
- تكتب اسمك وبريدك وكلمة مرور ← **تنصيب الآن** ← تصير أدمن المنصة.
- المفاتيح السرية تتولّد وتنحفظ تلقائياً (ما تحتاج تعدّل أي ملف).

### 3) شغّل محرك واتساب (Setup Node.js App)
صفحة التنصيب بعد ما تخلص تعرضلك القيم بالضبط. بشكل عام:

| الحقل | القيمة |
|---|---|
| Node.js version | أعلى نسخة (20 أو أحدث) |
| Application mode | Production |
| Application root | `domains/دومينك/public_html/wasel-engine` |
| Application URL | دومينك + `engine` |
| Application startup file | `app.js` |

بعدها: **Create** ← **Run NPM Install** ← **Restart**، وارجع حدّث `install.php` حتى تشوف «شغّال».

### 4) (مستحسن) Cron Jobs
أمر Cron كل 5 دقائق يطلعلك جاهز بصفحة `install.php` (للتذكيرات وإبقاء المحرك صاحي).

## حل المشاكل

| المشكلة | الحل |
|---|---|
| **403 Forbidden** | الملفات انفكت داخل مجلد فرعي. لازم `index.php` يكون مباشرة داخل `public_html`. وصلاحيات الملفات 644 والمجلدات 755 |
| **500 Internal Server Error** | نسخة PHP أقل من 8 ← غيّرها من Select PHP Version |
| ما يكدر ينشئ حساب | صار أكو تسجيل بالبريد وكلمة المرور يشتغل دائماً بدون واتساب أو كوكل |
| «محرك واتساب غير شغّال» | كمّل الخطوة 3، وبعدها حدّث `install.php` |
| «المفتاح السري غير مطابق» | بـ `install.php` اضغط «إعادة كتابة إعدادات المحرك» ثم Restart للتطبيق |
| Run NPM Install يفشل | اختار Node.js 20 أو أحدث |
| ما يطلع زر كوكل | حط Google Client ID من قسم «الإعدادات» بصفحة `install.php` |

صفحة `install.php` تبقى متاحة للأدمن لفحص النظام وتعديل الإعدادات بأي وقت.

## نقل البيانات من النسخة القديمة (app.db)
```
php tools/import_sqlite.php /المسار/إلى/app.db
```
(شغّله **قبل** فتح install.php، على موقع جديد فارغ. بعدها نصّب بنفس بريد الأدمن القديم)
