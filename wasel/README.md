# منصة واصل — PHP + JSON + تسجيل دخول بكوكل وواتساب

## تحديث (دقة تتبع القراءة والردود)
- كل رقم بالحملة صار بقائمة وحدة بس: **ردّوا / شاهدوا بدون رد / وصلت وما شاهدوا / ما وصلت بعد / فشلت**. اللي يرد ينشال تلقائياً من «شاهدوا بدون رد».
- اضغط على أرقام التقرير أو زر «مين رد ومين ما رد؟» حتى تشوف الأرقام، وتنسخها أو تنزّلها Excel أو **ترسل لهم حملة ثانية** (مثلاً تذكير للي شاهدوا وما ردّوا).
- إصلاحات: الحالات (الستوري) ورسائل المجموعات كانت تنحسب «رد» بالغلط، والرقم اللي يرجع من واتساب بصيغة ثانية ما كان ينشال من «بدون رد» لما يرد.
- ⚠️ حدّث محرك واتساب (النسخة 6) واضغط Restart. الحملات القديمة تبقى بالأرقام الإجمالية فقط.

## تحديث (البحث بالمتصفح + فحص المشاكل)
- **استخراج الأرقام من الخرائط بالمتصفح** بدل API (من «حسابي ← الإدارة ← استخراج أرقام من الخرائط»)، و3 طرق:
  1. **متصفح جهازي (إضافة كروم)** — الأفضل: نزّل الإضافة من نفس الصفحة ← فك الضغط ← `chrome://extensions` ← شغّل «وضع المطوّر» ← «تحميل إضافة غير مضغوطة». تفتح نافذة خرائط صغيرة وتبحث وتسجّل الاسم والرقم والعنوان والنوع والتقييم والموقع الإلكتروني، وترسلها للوحة تلقائياً.
  2. **متصفح السيرفر** — محرك واتساب يشغّل كروم مخفي (حزمة puppeteer اختيارية). يحتاج استضافة تسمح بتشغيل كروم (VPS غالباً)؛ بعد رفع المحرك اضغط **Run NPM Install** ثم **Restart**.
  3. **Google API** — الطريقة الرسمية المدفوعة (السابقة).
  - ⚠️ Google ما تسمح رسمياً بالسحب الآلي، وممكن تطلب «لست روبوت» لو كثر البحث: حلّه بنافذة الخرائط وأعد المحاولة.
- **زر «ابدأ الآن»** صار أعلى قليلاً ويبقى ظاهر حتى بالجوالات الصغيرة (كان يطلع خارج الشاشة بالجوالات القصيرة).
- إصلاح: نافذة «تثبيت التطبيق» داخل التطبيق كانت ترجع تظهر بكل زيارة إذا سدّيتها بالضغط برّاها.
- ⚠️ **حدّث محرك واتساب** (النسخة 5).

## تحديث (الواجهة التعريفية + تثبيت التطبيق)
- عند فتح الموقع أول مرة تظهر **واجهة تعريفية** متحركة: اللوجو، وصف المنصة، محادثة تجريبية، المزايا، خطوات الاستخدام، الباقات، طرق الدفع، المطوّر، وأسئلة شائعة.
- زرّين: **«استخدمه كتطبيق»** يفتح شاشة التثبيت ونافذة المتصفح مباشرة (مع شريط تقدّم)، وبالآيفون تظهر خطوات «إضافة إلى الشاشة الرئيسية». و**«استخدمه كموقع»** يخفي الواجهة وينقلك لتسجيل الدخول.
- بعد التثبيت أو اختيار «كموقع» ما تظهر الواجهة مرة ثانية، والتطبيق المثبّت يفتح مباشرة. تقدر ترجعها من زر «تعرّف على المنصة».

## تحديث (فلترة الأرقام + استخراج أرقام من الخرائط)
- **فلترة الأرقام بالحملة**: عدّاد (مكتوب / صالح / مكرر / ناقص) وأزرار «حذف المكرر» و«حذف الناقص» و«مسح».
- **استخراج أرقام من خرائط Google** (للأدمن فقط من «حسابي ← الإدارة»): اختر الدولة والمدينة ونوع النشاط (مثلاً البصرة + سيراميك)، ونجيب المحلات والشركات مع أرقامها. تقدر ترسل لهم حملة مباشرة أو تنزّلهم Excel.
  - يحتاج مفتاح Google Maps: من Google Cloud Console فعّل **Places API (New)** وسوّ API key، وحطه بالإعدادات أو بنفس الصفحة.
  - Google تحاسب على الطلبات (عندها رصيد مجاني شهري). البحث السريع ≈ 3 طلبات، المتوسط ≈ 13، الشامل ≈ 28.

## تحديث (الأمان الشامل + صفحة API)
- **صفحة ربط API كاملة**: خطوات وشرح الطلب والردود، وأمثلة جاهزة (cURL / PHP / Node.js / Python) مع زر نسخ.
- **الإشعارات**: شكل جديد، وتحذف الإشعار بسحبه يمين أو يسار، و«قراءة الكل» يتحول لـ«حذف الكل».
- حذف صفّي «الإشعارات» و«تثبيت التطبيق» من حسابي، وإضافة «الخصوصية والأمان».
- بعد اختيار الباقة وطريقة الدفع **يتحدد المبلغ تلقائياً** وما ينعدل.
- بطاقة صغيرة لامعة لاختيار **رمز الدولة** بكل مكان (الدخول، الحملة، الربط، الإعدادات).
- منع التكبير ونسخ النصوص (عدا الحقول والأكواد).
- بطاقة مطوّر صغيرة بصفحة الترحيب فوق زر «ابدأ الآن».
- صفحة **الخصوصية والأمان وشروط الاستخدام**: `/privacy`.
- **ملف install.php مقفول** بعد التنصيب (يرجع 404). للطوارئ استخدم **رابط الاسترجاع** اللي يظهر مرة وحدة بنهاية التنصيب — احفظه بمكان آمن.
- الحماية: ترويسات CSP/HSTS، منع CSRF، تحديد عدد الطلبات، تشفير Argon2id، كوكيز محمية، سجل أحداث الأمان وعمليات الأدمن، تنبيه عند محاولات دخول مشبوهة.
- **HTTPS إجباري**: من «الأمان» شغّل المفتاح بعد ما تتأكد إن شهادة SSL شغالة.

## تحديث (تحسينات شاملة)
- **الرد الذكي**: يتذكر المحادثة (ما يكرر الترحيب بكل رسالة) وما يقتبس رسالة العميل، وبطاقة تعليمات كاملة إلزامية لكل رقم قبل التفعيل.
- **تقارير الحملات**: نسبة النجاح، ومين استلم، ومين شاهد، ومين رد، ومين شاهد بدون رد (تتحدث لمدة 7 أيام).
- استيراد الأرقام من **جهات الاتصال** (أندرويد) أو ملف vcf.
- الحملة بصورة فقط ما ترسل «هلو»، والحملة الفارغة ترفض.
- تأكيد الحذف وتسجيل الخروج بنافذة من الأسفل. الإشعارات مرتبة (زر «تمت القراءة» يتحول لـ«حذف»).
- **بطاقة المطوّر** بقسم حسابي (الاسم والصورة والرقم من الإعدادات).
- **Cron برابط**: من الإعدادات ← «تنصيب Cron الآن»، وكذلك المهام تشتغل تلقائياً مع زيارات الموقع.
- **حماية**: ترويسات أمان، منع الطلبات المزوّرة من مواقع ثانية (CSRF).
- حذف الوضع الليلي وحذف «اشتراكات عملائي» من الواجهة، وتسريع التنقل وإصلاح الأزرار اللي تبقى تحمّل.
- ⚠️ **حدّث محرك واتساب** (مجلد wasel-engine) واضغط Restart: النسخة الجديدة (4) فيها ذاكرة المحادثة وتتبع الحملات.

## تحديث (ستايل B - زجاجي فاتح)
- تصميم زجاجي مثلّج فاتح بلون واحد (فيروزي الشعار)، بطاقات ناعمة لامعة، ورسومات توضيحية بدل الأماكن الفارغة.
- منيو كبسولة بيضاء: الصفحة المفتوحة تتوسع ويظهر اسمها، وانتقالات ناعمة بين كل الصفحات.
- صفحة ترحيب + صفحة دخول (زر Google وتحته واتساب) بنفس الستايل.

## تحديث سابق (تصميم واصل الجديد)
- لون الموقع والتطبيق صار من شعار واصل (فيروزي)، وشعارك صار الشعار الافتراضي وأيقونة التطبيق.
- تصميم جديد كامل: بطاقات ملوّنة متدرجة، أزرار كبسولية، منيو داكن عائم بزر «حملة جديدة» بالوسط، وصفحة دخول جديدة.
- **الباقات** بدل الشحن: الأدمن يضيف باقات (سعر، مدة، مزايا، لون، «الأكثر طلباً»). المستخدم يضغط الباقة ويدفع من رصيده أو بأي طريقة دفع، وتتفعّل تلقائياً بعد وصول المبلغ. وتحتها خيار «الدفع حسب الرسائل».
- نافذة «ثبّت التطبيق» تطلع من الأسفل وتختفي (مو بطاقة ثابتة).
- روابط الأدمن صارت مباشرة: `/users` ، `/settings` ، `/plans` ، `/dashboard` ... والمستخدم يبقى على `/app`.
- **خطأ not found عند طلب رمز الربط**: سببه أن محرك واتساب على السيرفر نسخة قديمة. ارفع مجلد `wasel-engine` الجديد (بدون حذف مجلد `data` داخله) واضغط **Restart** من Setup Node.js App.

## الجديد بالنسخة السابقة
- تصميم جديد كامل بنفس ستايل لوحة SMM (بطاقات، منيو سفلي عائم، انتقالات متحركة).
- تسجيل الدخول: زر **كوكل** فقط، وتحته **تسجيل برقم واتساب** (رمز تحقق). بريد الأدمن ينحدد بصفحة التنصيب.
- ربط أرقام واتساب **بالباركود** أو **برمز الربط** (الأجهزة المرتبطة ← الربط برقم الهاتف).
- **محفظة بالدينار**: شحن عبر آسياسيل (تلقائي برمز SMS)، Binance Pay (تحقق تلقائي من رقم العملية + سعر الدولار يحدده الأدمن)، سوبر كي، وتحويل يدوي بإيصال.
- الأدمن يحدد **سعر كل رسالة**: المستخدم بدون اشتراك تنخصم من رصيده كل رسالة، أو يشتري **اشتراك** من رصيده.
- لوحة أدمن: المستخدمين (رصيد/اشتراك/تجربة/حظر)، طلبات الشحن، طرق الدفع وشعاراتها، الإعدادات، **مركز الأمان**، **نسخ احتياطي JSON عبر بوت تيليجرام**، إعلان جماعي.
- المستخدم يبقى على `/app` فقط، والأدمن كل قسم إله رابط (`/app/users`، `/app/settings`...).
- الموقع ينثبت كتطبيق (PWA) وأيقونته تصير شعارك تلقائياً.


## التنصيب (3 خطوات)

### 1) ارفع الملفات
1. من DirectAdmin ← **File Manager** ← ادخل `public_html` وامسح ملفات الموقع القديم.
2. ارفع `wasel-full.zip` داخل `public_html` واضغط **Extract**.
3. لازم تشوف مباشرة داخل `public_html`: `index.php`، `install.php`، مجلد `wasel-engine`... (مو مجلد واحد فيه كل شي).

### 2) افتح صفحة التنصيب
افتح `https://دومينك/install.php`:
- تفحص السيرفر وتكلك إذا أكو مشكلة وشلون تحلها.
- تكتب اسمك و**بريد كوكل اللي راح تدخل بيه** وكلمة مرور طوارئ ← **تنصيب الآن** ← تصير أدمن المنصة.
- بعدها حط **Google Client ID** (من الإعدادات بلوحة الأدمن أو من install.php) حتى يشتغل زر كوكل.
- المفاتيح السرية تتولّد وتنحفظ تلقائياً (ما تحتاج تعدّل أي ملف).

### 3) شغّل محرك واتساب (Setup Node.js App)
صفحة التنصيب بعد ما تخلص تعرضلك القيم بالضبط. بشكل عام:

| الحقل | القيمة |
|---|---|
| Node.js version | أعلى نسخة (20 أو أحدث) |
| Application mode | Production |
| Application root | `domains/دومينك/public_html/wasel-engine` |
| Application URL | دومينك + `engine` |
| Application startup file | `app.js` |

بعدها: **Create** ← **Run NPM Install** ← **Restart**، وارجع حدّث `install.php` حتى تشوف «شغّال».

### 4) (مستحسن) Cron Jobs
أمر Cron كل 5 دقائق يطلعلك جاهز بصفحة `install.php` (للتذكيرات وإبقاء المحرك صاحي).

## حل المشاكل

| المشكلة | الحل |
|---|---|
| **403 Forbidden** | الملفات انفكت داخل مجلد فرعي. لازم `index.php` يكون مباشرة داخل `public_html`. وصلاحيات الملفات 644 والمجلدات 755 |
| **500 Internal Server Error** | نسخة PHP أقل من 8 ← غيّرها من Select PHP Version |
| ما يكدر ينشئ حساب | صار أكو تسجيل بالبريد وكلمة المرور يشتغل دائماً بدون واتساب أو كوكل |
| «محرك واتساب غير شغّال» | كمّل الخطوة 3، وبعدها حدّث `install.php` |
| «المفتاح السري غير مطابق» | بـ `install.php` اضغط «إعادة كتابة إعدادات المحرك» ثم Restart للتطبيق |
| Run NPM Install يفشل | اختار Node.js 20 أو أحدث |
| ما يطلع زر كوكل | حط Google Client ID من قسم «الإعدادات» بصفحة `install.php` |

صفحة `install.php` تبقى متاحة للأدمن لفحص النظام وتعديل الإعدادات بأي وقت.

## نقل البيانات من النسخة القديمة (app.db)
```
php tools/import_sqlite.php /المسار/إلى/app.db
```
(شغّله **قبل** فتح install.php، على موقع جديد فارغ. بعدها نصّب بنفس بريد الأدمن القديم)
