# تمريني — جدول التمارين والوجبات (PWA + PHP + JSON)

تطبيق ويب يتثبّت على الجوال مثل التطبيقات (PWA)، بنفس ستايل «واصل»، وقاعدة بياناته ملفات JSON (بدون MySQL).

## شنو يسوي؟
- **برنامج أسبوعي:** أيام تمرين (D1, D2 ...) وتحدد لكل يوم بالأسبوع شنو تتمرن (أو راحة). البرنامج الافتراضي مأخوذ من ورقة الجيم، وتكدر تعدّله كله.
- **51 تمرين برسوم متحركة:** كل تمرين بيه رسم متحرك يبين الحركة، والعضلة الشغّالة باللون الأحمر، و«على شنو يشتغل»، وطريقة الأداء، ونصيحة.
- **أجهزة قاعتي:** تعلّم الأجهزة الموجودة بقاعتك، فيعرضلك التمارين اللي تكدر تسويها بس، ويقترح بدائل للتمارين اللي تحتاج جهاز مو موجود.
- **جلسة التمرين:**
  - زر «أكملت المجموعة» لكل مجموعة، ويكتب الوزن ويتذكره للمرة الجاية.
  - **مؤقت راحة** بدائرة عدّ تنازلي، ومعه ‎+15/-15 وزر تخطي.
  - لما تخلص الراحة يوصلك **صوت + اهتزاز + إشعار**.
  - إشعار لما **تكمّل كل تمرين**، وإشعار لما **تكمّل تمرين اليوم**، وبعدها شاشة احتفال.
  - الشاشة تبقى شغّالة طول التمرين (Wake Lock). ولو سكّرت التطبيق، ترجع تكمّل من نفس المكان.
- **الوجبات:** جدول وجبات بأوقات، و**إشعار يومي بوقت كل وجبة** حتى لو التطبيق مسكّر. ويه تذكير اختياري لشرب الماي.
- **حسابي:** الوزن والطول والعمر والهدف، والسجل، والأيام المتتالية، والوضع الداكن، وتغيير كلمة السر.
- **صورتك أو GIF مالك:** تكدر ترفع صورة أو فيديو قصير لأي تمرين، ويطلع بدل الرسم.
- **يشتغل بدون إنترنت** بعد أول فتحة.

## التنصيب (استضافة مشتركة مثل DirectAdmin)
1. ارفع **محتويات** مجلد `site/` لجذر الدومين أو الدومين الفرعي (مثلاً `public_html`).
2. خلّي مجلد `data/` قابل للكتابة (755 أو 775).
3. فعّل **HTTPS**، لأن التثبيت والإشعارات ما تشتغل بدونه.
4. **Cron كل دقيقة**، حتى توصل إشعارات الوجبات ونهاية الراحة والتطبيق مسكّر:
   ```
   * * * * * php /home/USER/domains/DOMAIN/public_html/cron.php
   ```
   أو رابط: `https://موقعك/cron?key=المفتاح`. المفتاح موجود بـ `data/config.json` (`cron_key`).
   بدون Cron، التنبيهات تشتغل بس لما أحد يفتح التطبيق.
5. افتح الموقع وسوّ حساب.
6. (اختياري) بـ `data/config.json` حط `"contact": "your@email"` حتى يكون عنوان تواصلك ويّا خدمات الإشعارات.

## الإشعارات (Web Push بدون مكتبات)
- مفاتيح VAPID تتولد تلقائياً أول تشغيل.
- السيرفر يرسل تنبيه فارغ، والمتصفح يسأل `/api/push/inbox` عن النص.
- **أندرويد:** Chrome وغيره يشتغل مباشرة.
- **آيفون:** لازم تثبّت التطبيق على الشاشة الرئيسية أول (iOS 16.4 أو أحدث).

## الحماية
- كلمات السر مشفّرة (`password_hash`).
- حدّ لمحاولات الدخول.
- كل طلبات التعديل تحتاج ترويسة الواجهة وتتأكد من نفس المصدر (ضد CSRF).
- كل المدخلات تنظّف قبل الحفظ.
- الملفات المرفوعة يتفحص نوعها الحقيقي، والحد 8MB، وتنعرض بس لصاحبها.
- مجلد `data/` محمي من التصفح.
- ترويسات أمان وCSP.

## تطوير
- مكتبة التمارين: عدّل `tools/build_exercises.py` وشغّله، وراح يكتب `site/views/exercises.json`.
- الرسوم المتحركة: `site/views/anim.js`، لكل حركة وضعيتين A وB.
- الأيقونات: `python3 tools/build_icons.py /path/to/node_modules` (يحتاج `@fortawesome/fontawesome-free@6.5.1`).
