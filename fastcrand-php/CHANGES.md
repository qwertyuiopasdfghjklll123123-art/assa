# FastCrand index.php — مراجعة وإصلاحات

## ثغرات أمنية حرجة
1. **كشف مجلد `data/`**: كان أي شخص يفتح `data/site_config.json` فيرى هاش كلمة مرور المدير وتوكن بوت تيليجرام، و`data/demo_requests.json` بأسماء وأرقام العملاء. → يُنشأ `data/.htaccess` يمنع الوصول.
2. **رفع SVG = XSS مخزّن**: صور SVG تنفّذ JavaScript على نفس الدومين. → منع SVG، التحقق من محتوى الصورة الحقيقي (`getimagesize`)، ومنع تنفيذ السكربتات داخل `uploads/`.
3. **Path Traversal في تنزيل APK**: حقل `existing_apk_file` كان يُقبل كما هو، فيمكن جعله `../data/site_config.json` ليُحمَّل للزوار. → يُقبل فقط إن طابق ملف التطبيق الحالي.
4. **لا توجد حماية CSRF**: روابط الحذف (GET) والنماذج يمكن تنفيذها من موقع خارجي على المدير. → رمز CSRF في كل النماذج والروابط.
5. **XSS في الواجهة**: كل البيانات كانت تُدرج بـ `innerHTML` بدون تهريب. → دالة `esc()` لكل القيم، و`safeHref()` لمنع روابط `javascript:`.
6. **تسجيل الدخول**: لا تجديد لمعرّف الجلسة ولا حد للمحاولات. → `session_regenerate_id` + قفل 5 دقائق بعد 5 محاولات خاطئة + كوكيز `HttpOnly/SameSite/Secure`.
7. **تعطيل التحقق من SSL** مع تيليجرام. → تم تفعيله والتحقق من صيغة التوكن.

## أخطاء منطقية
- حفظ إعدادات تيليجرام كان **يعيد حالة الإنستغرام إلى "معطل"** في كل مرة.
- عند عدم وجود APK كان الموقع يرسل **ملف APK تالف** (نص). الآن يفتح رابط المتجر/الويب أو يظهر "قريباً".
- شارة "يوجد ملف APK مرفق" كانت **تظهر دائماً** (خاصية `display` مكررة).
- مستمع التمرير كان **يتراكم مع كل تغيير لغة** (تسريب أداء).
- ملفات JSON تُكتب الآن بقفل وبشكل ذري لمنع تلفها وفقدان عدّ الزوار/التحميلات.
- عداد التحميل يُحسب مرة واحدة لكل جلسة، التقييمات تُقبل لتطبيقات موجودة فقط، وتحديد معدل/طول لطلبات "ابدأ الآن" + حقل honeypot ضد البوتات.
- حذف تطبيق/مقال يحذف ملفاته المرفوعة أيضاً، وروابط `fetch` تعمل حتى لو تغيّر اسم الملف.
- صلاحيات المجلدات `0755` بدل `0777`، وتعيين المنطقة الزمنية.

## ملاحظة
كلمة المرور الافتراضية ما زالت `admin123` للتوافق؛ تظهر الآن رسالة تحذير في لوحة التحكم حتى تغييرها (8 أحرف على الأقل).

## تحديث: مشاريع قيد التطوير + ترتيب "عرض الكل" + السرعة
- **مشروع تحت العمل:** في نموذج التطبيق حقلان جديدان "حالة المشروع" و"نسبة الإنجاز %". المشروع قيد التطوير يظهر بشارة 🚧 وزر "قريباً"، وفي صفحته شريط إنجاز بدل أزرار التحميل، والسيرفر يرفض تحميله.
- **عرض الكل:** ترويسة بالعدد + فلاتر (الكل / المنشورة / قيد التطوير) + مجموعتان منفصلتان، وبطاقات أكبر فيها التصنيف والتحميلات والتقييم.
- **السرعة:** إزالة `blur` الثقيل عن الأقسام (كان يعيد رسم الصفحة كلها مع كل تمرير) واستبداله بتعتيم خفيف؛ إزالة `blur(80px)` من الخلفية؛ تبديل الوضع الداكن فوري (إيقاف الانتقالات لحظياً)؛ تحديد معالج التمرير بـ requestAnimationFrame؛ إيقاف حركة الشريطين خارج القسم النشط أو عند فتح نافذة؛ تضمين البيانات في الصفحة بدل طلب إضافي؛ تحرير قفل الجلسة مبكراً؛ preconnect للخطوط والأيقونات.

## تحديث: الموقع عربي فقط
حذف زر تبديل اللغة، وقاموس الإنجليزية، وكل حقول الإنجليزية من لوحة التحكم (التطبيقات والمقالات والإعدادات) ومن معالجة الحفظ والبيانات الافتراضية. الحقول الإنجليزية القديمة في ملفات JSON تُتجاهل بلا ضرر.

## تحديث: تقسيم الملفات + تصميم زجاجي
- **3 ملفات:** `index.php` (الخادم + HTML)، `assets/style.css`، `assets/app.js`. الثوابت القادمة من PHP (البيانات، المسار، رمز CSRF) تُمرَّر عبر `window.FC`. الروابط فيها `?v=` لتحديث الكاش تلقائياً. **ارفع المجلد `assets/` مع `index.php`.**
- **الفحص:** `php -l` و`node --check` بلا أخطاء، توازن أقواس CSS، كل المعرّفات (IDs) والدوال المستدعاة من الأزرار موجودة، تشغيل في متصفح بلا أخطاء JS أو ملفات 404.
- **عرض الكل:** بطاقات زجاجية (blur + شفافية + حدود لامعة)، خلفية كتل ملوّنة عائمة، دخول متتالي للبطاقات، لمعة زجاجية تمر فوقها، أيقونات تطفو، لون توهّج لكل تطبيق، ويدعم الوضع الداكن وتقليل الحركة.
